# PaxoInsight 6.1.5 — адаптивный логотип

21 октября 2026 года. Локальный Windows portable-кандидат, CPython 3.14.8 x64/GIL.

Причина белого прямоугольника в 6.1.4 — два виджета с фиксированным `#FFFFFF`.
Исходный PNG уже прозрачен. В шапке и «О программе» теперь используется
`AdaptiveLogo`: неизменённая эмблема показывается через Canvas с отсечением
области просмотра; надпись — средствами Tk, шрифтом интерфейса. Цвет Paxo и
фон привязаны к теме, Insight сохраняет фирменный синий. Размеры сохранены:
192×58 в шапке, 384×116 в «О программе». Исходный PNG не редактировался.

SHA-256 исходного `assets/paxoinsight-logo.png`:
`fb9aa0f2f3db2ddd203e44ae2997bb79594a9e5893dc02c0bfaea9f951cfb367`.

Проверено:

- 197 тестов: 196 успешны, один пропущен по POSIX-платформе; ошибок нет,
  время 36,090 с. В том числе 15 проверок оформления/настройки.
- На настоящих скрытых Tk-виджетах: фон всех частей логотипа и цвет надписи,
  повторные переключения, обе области показа, размеры и отсутствие обрезки текста,
  сохранение PNG-данных общего изображения. Это не интерактивная визуальная
  приёмка всех шрифтов/DPI и версий Windows.
- Ruff для изменённых Python-файлов прошёл. Bandit: 0 HIGH, 0 MEDIUM, 72 LOW;
  один внутренний тест пропущен. Полный новый аудит безопасности не проводился.
- Проверены 23 точные версии зависимостей, Python DLL и совпадение 21 встроенного
  критичного модуля с исходниками. Библиотеки не менялись и не добавлялись.
- Готовый ZIP распакован в новую временную папку: CRC ZIP и хеши/размеры
  259 файлов совпадают с манифестом; три самотеста EXE прошли без overrides.
  GUI-самотест дополнен проверкой логотипа на обеих темах.

  на текущем исходном ядре; включение ядра в EXE подтверждено отдельно.
