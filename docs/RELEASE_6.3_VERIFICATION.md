# Проверка выпуска PaxoInsight 6.3

23 октября 2026 года, Windows Standalone. Выпуск подготовлен в существующей
центральной ветке `main`; тег — `v6.3`. Новая ветка и PR не создаются.
Серверный код, базы пользователей, `.env`, пароли и рабочие данные в выпуск
не включены. Standalone-тесты ядра выделены из общего файла аудита без
импорта серверных библиотек; рабочая Web-версия не изменялась.

## Результаты

- **158 тестов Standalone прошли**, без ошибок и пропусков, 5,665 с.
- На реальной Kotlin stdlib 2.4.21 прочитано 995 class-файлов за 0,4282 с;
  подтверждено сопоставление `Tuples.kt` с `Pair`, `Triple`, `TuplesKt`.
  JAR использовались как данные, не выполнялись и в portable не входят.
- На настоящих скрытых Tk-виджетах проверены статусы, пути, 50% → 100%
  при повторном анализе и сброс при новом задании. Регрессии включают
  обе темы, адаптивный логотип, TXT-меню, пароли и сохранность текущего задания.
- Синтетический контроль TGZ: 50 архивов, 7 500 файлов, подготовка 10,8069 с,
  полных проверок рабочей области — 2. Не гарантия скорости реальных архивов.
- Ruff для изменённых проверяемых модулей прошёл.
- Bandit Standalone: 0 HIGH, 0 MEDIUM, 72 LOW, один внутренний тест пропущен.
  Это не новый полный аудит безопасности, не fuzzing и не проверка CVE библиотек.
- `pip check` успешен; подтверждены 23 точные версии runtime/build-библиотек,
  CPython 3.14.8 x64/GIL, Python DLL и совпадение 21 критичного модуля EXE с исходниками.
- Готовый ZIP распакован в новую временную папку: проверены CRC и SHA-256/размеры
  259 файлов по манифесту. Без Python/backend overrides успешно выполнены
  `--self-test`, `--gui-self-test`, `--security-self-test`.
- Три публичных RAR3/RAR5 fixture с установленным 7-Zip: неверный пароль → верный,
  список/размеры, нативная целостность, обычные CRC где применимо, очистка и
  сохранность источника. Это проверка исходного ядра; его включение в EXE
  подтверждено отдельно сравнением встроенных модулей.

Границы: текущая Windows 11, не отдельная чистая VM; нет интерактивной визуальной
приёмки всех DPI/шрифтов и полной сертификации безопасности. EXE не подписан.
Прежние остаточные риски из аудита не объявляются автоматически устранёнными.
