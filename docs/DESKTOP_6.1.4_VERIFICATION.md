# Проверка Standalone 6.1.4

21 октября 2026 года. Локальный Windows portable-кандидат, CPython 3.14.8 x64/GIL.
[Описание TXT и тем](DESKTOP_6.1.4.md).

## Проверки

- Полный прогон: 195 тестов, 194 успешны, один пропущен по POSIX-платформе;
  ошибок и падений нет, 33,775 с. В том числе локальные Web-тесты; рабочий
  Web-сервис не менялся.
- 13 проверок настройки/палитр/Tk и 8 тестов отчётности: HTML/TXT-меню,
  кодировка кириллицы, частичный комплект с 50%, отсутствующий класс,
  атомарная запись и сохранность прежнего файла при ошибке.
- На настоящих скрытых Tk-виджетах: обе темы, сохранение/восстановление выбора,
  переключение при занятом приложении, сохранность задания, результатов,
  журнала, вкладки, выделения строк и прогресса; «О программе» и окно пароля.
  Системные диалоги и внешний вид на всех версиях Windows визуально не проверялись.
- Для основных семантических пар текста обеих палитр проверен контраст ≥ 4,5:1.
- Повреждённый, неизвестный, слишком большой или глубоко вложенный JSON настройки
  не блокирует запуск. Отказ записи не отменяет тему текущего запуска.
- Ruff для изменённых проверяемых Python-файлов прошёл без замечаний.
- Bandit Standalone: 0 HIGH, 0 MEDIUM, 72 LOW; один внутренний тест пропущен.
  Это не новый полный аудит безопасности, не fuzzing и не проверка CVE библиотек.
- `pip check` успешен, проверены 23 точные версии runtime/build-зависимостей.
  Библиотеки не обновлялись и не добавлялись; Python остался 3.14.8.
- Проверены совпадение Python DLL и 20 встроенных критичных модулей с исходниками,
  отсутствие запрещённых старых Qt/CPython/backend-модулей.
- Готовый ZIP заново распакован в отдельную временную папку; проверены CRC ZIP
  и SHA-256/размер 259 файлов по манифесту. Без Python/backend overrides прошли
  `--self-test`, `--gui-self-test`, `--security-self-test`.
- Замороженный функциональный самотест проверяет оба TXT-экспортёра с 50%
  и `demo/Missing.class`; GUI-самотест проверяет обе темы и пункт TXT.
- Три публичных RAR3/RAR5 fixture с установленным 7-Zip: неверный пароль → верный,
  список/размеры, нативная целостность, обычные CRC где применимо, очистка и
  сохранность источника. Это проверка текущего исходного ядра; включение ядра
  в EXE подтверждено отдельно сравнением модулей.

Проверки выполнены на текущей Windows 11, не на отдельной чистой VM.
Пользовательская настройка темы при тестировании не перезаписывалась.
Прежние остаточные риски безопасности не объявляются устранёнными.

## Сборка

- ZIP: `dist/PaxoInsight_v6.1.4_Python3148_Portable.zip`, 22 544 837 байт.
- SHA-256 ZIP: `c57d2fb29cce8fdda174f22bc70fb0dc05b24f1e954f0999be1eba0552dee834`.
- EXE: `dist/desktop-6.1.4/PaxoInsight/PaxoInsight.exe`.
- SHA-256 EXE: `297a391d77de710c7a5b9ec38a09b22cbf994ebe778cc87313322912bb047920`.
- Внутри ZIP: SBOM (Python, 15 библиотек, 125 нативных PE-файлов), файловый
  манифест SHA-256, BUILD_VERIFICATION.json и SECURITY_SELF_TEST.json.
- Старый ZIP 6.1.3 сохранён с прежним SHA-256:
  `87c9f76d3bd62711c33ae1b9f9daa13c8ee0f45bc778c057dfd068bddf4a6462`.
- GitHub, теги и рабочий Web-сервис не обновлялись.

Первая проверка сборки остановила процесс до PyInstaller из-за старого
`src/paxoinsight.egg-info` версии 6.1.3. Метаданные проекта синхронизированы с
6.1.4, после чего все проверки сборки прошли. Библиотеки не заменялись.
