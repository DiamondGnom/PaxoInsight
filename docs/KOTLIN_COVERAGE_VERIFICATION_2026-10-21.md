# Проверка Kotlin-покрытия: PaxoInsight 6.1.3

Дата: 21 октября 2026 года. Локальный Windows portable-кандидат.
Исходники: `C:\Paxo\PaxoInsightApp`. Python: CPython 3.14.8 x64, GIL.

## Результат

Оценочный процент и подтверждённая доля отображаются во вкладке Kotlin,
в заключении и экспортах HTML/TXT/JSON. Формула, изменения точности и границы
описаны в [KOTLIN_COVERAGE_6.1.3.md](KOTLIN_COVERAGE_6.1.3.md).

Это показатель сопоставления исходников и ожидаемых JVM-артефактов. Он не
измеряет покрытие SAST, тестов или строк и не доказывает тождество исходников
и байткода. При неполном разборе оценка явно помечается неполной.

| Kotlin и формула | 65 тестов: объявления, метаданные, контексты сборки, частичные и неоднозначные связи, консервативные проценты, н/д и разделение main/test |
| Настоящий Kotlin | Прочитано 995 class-файлов официальной Kotlin stdlib 2.4.21 за 0,4227 с; `Tuples.kt` структурно связан с `Pair.class`, `Triple.class`, `TuplesKt.class` |
| Tk | На настоящих скрытых виджетах проверены 7 колонок, реальные пути и статусы, 50% → 100% после повторного анализа и сброс при новом задании. Это не визуальная приёмка интерактивного окна |
| Ruff | Все изменённые проверяемые Python-модули и тесты прошли проверку |
| Bandit Standalone | 0 HIGH, 0 MEDIUM, 72 LOW; один внутренний тест анализатора пропущен. Не заменяет ручной аудит, fuzzing или проверку CVE зависимостей |
| TGZ | 50 синтетических TGZ, 7 500 файлов: подготовка 10,3498 с, полных проверок рабочей папки — 2. Не замер анализа Kotlin и не гарантия времени на реальном архиве |
| Зависимости сборки | `pip check` успешен; проверены 23 точные версии. Новых библиотек и Java/JRE не добавлено |
| Замороженный код | 19 критичных модулей совпадают с исходниками; Python DLL совпадает с 3.14.8; запрещённые старые Qt/CPython-модули отсутствуют |
| EXE из готового ZIP | В новой временной папке прошли `--self-test`, `--gui-self-test`, `--security-self-test` без Python/backend overrides |
| ZIP и манифест | Проверены CRC ZIP и SHA-256/размер 259 файлов по манифесту |
| RAR | Три публичных RAR3/RAR5 fixture: неверный пароль → верный, список/размеры/нативная целостность, дополнительные обычные CRC там, где применимо, очистка и сохранность входного файла. Проверено текущее исходное ядро с установленным 7-Zip; его включение в EXE проверено отдельно |

Проверка portable выполнялась на текущей Windows 11, не на отдельной чистой VM.
Самотест EXE содержит частичный Kotlin-комплект с оценкой и подтверждённой
долей 50%. Тестовые JAR не выполняются и не поставляются с приложением.
Ранее отмеченные остаточные риски безопасности не объявляются устранёнными.
