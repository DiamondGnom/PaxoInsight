# PaxoInsight 6.3

23 октября 2026 года. Windows Standalone, CPython 3.14.8 x64 с GIL.
Выпуск объединяет накопленные изменения после опубликованной версии 6.1.

## Критическое исправление RAR в составе 6.3

Обновлена уже опубликованная 6.3 по решению владельца проекта. В первоначальной
сборке проверка ZIP по концу файла могла принять настоящий RAR с сохранённым
в нём ZIP за Java resource adapter: вместо всего RAR читался последний ZIP,
а остальные записи не попадали в анализ.

Теперь формат проверяется по сигнатуре в начале файла. Настоящие RAR3/RAR5
распаковываются 7-Zip независимо от флажка JAR-контейнеров; ZIP-формат `.rar`
для Java/Jakarta сохранён. Проверяются пути и размеры всех результатов RAR,
запрещены дубли и конфликты файл/каталог. При расхождении, даже во вложенном
RAR, анализ прерывается, исходный архив не удаляется.

Скачавшим первоначальную 6.3 нужно повторно скачать ZIP, проверить новую сумму
SHA-256 и распаковать в новую пустую папку. Пропущенные прежней сборкой файлы
не восстанавливаются повторным анализом рабочего каталога: нужен исходный RAR.

## Основные изменения

- **Kotlin/JVM:** вместо сравнения имён — структурное сопоставление объявлений
  с внутренними именами `.class`, `SourceFile` и заголовками `kotlin.Metadata`.
  Учтены package, модули, тестовые наборы, вложенные/companion-классы,
  `JvmName`, multifile-фасады и выходы Multiplatform.
- **Проценты:** оценочный и подтверждённый показатели Kotlin → `.class`,
  отдельно основной код и тесты. Частичные файлы учитываются пропорционально;
  неоднозначные и непроверенные связи не считаются подтверждёнными.
- **Отчёты:** Kotlin HTML/TXT и полное заключение TXT через меню «Отчёт».
  Сохраняются статусы, ожидаемые классы, реальные пути и основания; TXT — UTF-8
  с BOM, запись атомарная. JSON и включение отчётов в итоговый 7Z сохранены.
- **Темы:** «Вид → Тема оформления → Светлая / Тёмная»; смена не сбрасывает
  задание, результаты и журнал. Адаптированы таблицы, подсветка, окно пароля,
  «О программе» и логотип без белой подложки. Сохраняется только имя темы.
- **Runtime и сборка:** CPython 3.14.8, проверенные версии зависимостей,
  lock/hash-файлы, контроль Python DLL и совпадения критичных модулей EXE
  с исходниками. SBOM дополнен реальными нативными PE-файлами и SHA-256.
- **Распаковка:** ограничение фактических файлов, каталогов, байтов и свободного
  места, защищённый XML, запрет ссылок и дублей. RAR использует установленный
  7-Zip с паролем через stdin, без неявного запуска распаковщика комментариев.

Сохранены ускоренная обработка множества TGZ, подсказка повторного анализа
BAR/JAR-контейнеров, вставка пароля, входные папки и создание проверенного 7Z
по нажатию кнопки. В Standalone нет базы и истории заданий.

## Установка

В релизной копии Standalone прошли **172 автоматических теста**, без ошибок
и пропусков; серверные библиотеки для этого прогона не требуются.
Проверка готового EXE и протоколы публикации находятся в
[RELEASE_6.3_VERIFICATION.md](RELEASE_6.3_VERIFICATION.md).

1. Скачайте `PaxoInsight_v6.3_Python3148_Portable.zip`.
2. Сверьте SHA-256 с `PaxoInsight_v6.3_SHA256.txt`.
3. Полностью распакуйте ZIP в новую пустую папку.
4. Запустите `PaxoInsight.exe` рядом с каталогом `_internal`.

Python уже включён в portable. Для RAR нужен установленный 7-Zip.
Запуск одного EXE отдельно от `_internal` не поддерживается.
Вложения и тег текущей 6.3 обновлены; более ранние версии не изменялись.

## Границы анализа и безопасности

Проценты показывают комплектность сопоставления Kotlin/JVM, не покрытие SAST,
тестов, строк или уязвимостей. Они не доказывают сборку из данной версии исходников.
Полные AST, protobuf d1/d2, DEX, SMAP и семантика методов не анализируются.
Java, Gradle и код из неизвестных архивов для этой проверки не запускаются.

PaxoInsight не заменяет антивирус, SAST или изолированную среду. EXE не подписан;
полный fuzzing нативных декодеров и отдельная чистая Windows VM не проверялись.
Не запускайте программу с правами администратора, контролируйте диск,
для недоверенных архивов используйте ограниченную учётную запись/изоляцию.
Новое оформление и регрессионные проверки не устраняют автоматически все риски,
описанные в материалах аудита.
